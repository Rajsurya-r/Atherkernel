# AetherKernel: Speculative In-Memory Code Synthesis Runtime

High-Performance Graph Caching, Weight-Decomposed Model Adaptation, and Resilient Agentic Governance for Systems Monorepos.

## Architecture
- **CPG Engine (`src/cpg_engine.py`):** In-memory Abstract Syntax Tree indexing via KuzuDB and Tree-sitter.
- **Agent Gatekeeper (`src/agent_gatekeeper.py`):** Ephemeral compiler verification sandbox and HITL consensus gate.
- **Telemetry (`src/telemetry_dora.py`):** Prometheus exporter for DORA operational metrics on port 9100.
- **DoRA Adaptation (`train/train_dora_fim.py`):** Fill-in-the-Middle PEFT fine-tuning script.
- **Demo Runner (`run_exam_demo.py`):** End-to-end pipeline execution with live UI on port 3000.
